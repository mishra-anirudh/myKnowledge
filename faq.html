HTML FAQ

What is HTML?
HTML is also called Hyper Text Markup Language. Which is the building block of web structure and the content we see.
Whatever we see while visiting a page is fundamentally HTML behind the scene.
Why is it useful?
HTML is useful because it provides a valid structure for the content we see. It provides the hierarchical meaning to the content.
Technologies working together with HTML?

HTML is not alone it works in a team of technology which provides the appearence and functionality to the page we visit.

Yes you have guessed it correctly. I am talking about CSS (Cascading Style Sheet) and JS (JavaScript) but we are not going to talk about them here for now.
